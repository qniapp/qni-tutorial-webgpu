## 原のt5

本文は上から4量子ビットを A1,A4,B1,B4 と割り当てる。つまり q0=A1,q1=A4,q2=B1,q3=B4。

原JSONの列37〜43は:

```json
[["{t5 = ¬A4 ∨ ¬B4"],[1,"X","X"],[1,"X","X"],[1,"•","•",1,1,1,1,1,"X"],[1,"X","X",1,1,1,1,1,"X"],[1,"X","X"],["}"]]
```

入力操作と2つのcontrolはq1,q2を使っており、実際に計算するのは **¬A4 ∨ ¬B1**。結果t5はq8 (9番目のwire)。末尾のuncomputeも同じq1,q2の逆操作を使う。
