## 周波数・確率・回路の答は正しい

N=16、入力は a_j=(1/4)exp(iπj/4)=(1/4)exp(2πi·2j/16)。

- 各 |a_j|²=1/16=6.25%。
- 軸上の値は±0.25/±0.25i。
- 斜めの実部/虚部は±1/(4√2)=±0.1767766952966369。原の±0.17678は小数5桁の丸めとして一致する。
- 位相差π/4=45°、周期8。16個の標本には8個のパターンが2回含まれる。周波数2は正しい。
- 原の負指数QFT回路では b_k=(1/16)Σ[j=0..15] exp(2πi(2-k)j/16)=δ[k,2]。
- よって最終 |2⟩ の振幅+1/確率100%、他0。測定で答2を取り出す説明は正しい。
- 均等な位相回転では平均0で、平均についての反射だけでは大きさの均等性は変わらない。

## 端点の違い

| j | 位相の進み (unwrapped) |
|---|---|
| 0 | 0° |
| 7 | 315° |
| 8 | 360° |
| 15 | **675° = 1.875回転** |

0から15までの間隔は15個なので15×45°=675°。2回転=720°に到達するのは周期的な続きのj=16であり、4-qubitの実際の状態ラベルは0〜15まで。このため「|15⟩までで位相が2回転」という端点表現を厳密に読むと、16標本に2周期を含むという意味とは異なる。周波数を1.875に変えることは提案しない。
